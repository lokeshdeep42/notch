# Sill v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship all v1 features of Sill (notch engine, Now Playing, shelf, clipboard, power, settings, onboarding) — no licensing — as a SwiftPM app that builds and tests green on a macOS CI runner.

**Architecture:** SwiftPM targets layered `DesignSystem ← Services ← NotchCore ← Feature* ← SettingsUI ← Sill`. One borderless `NSPanel` per display with a fixed frame; a pure reducer (`NotchStateMachine`) owns the phase; features plug in through the `NotchModule` protocol. Event-driven everywhere; the only repeating timer is the opt-in clipboard `changeCount` poll.

**Tech Stack:** Swift 5.9+ (Swift 5 language mode), AppKit + SwiftUI, IOKit, QuickLookThumbnailing, XCTest, GitHub Actions `macos-15`.

## Global Constraints

- macOS **14.0+**; bundle id `app.sill.Sill`; name from `Branding.appName` only.
- Idle CPU ≤ **0.1%**, RSS < **80 MB**, no repeating timers while collapsed except the clipboard poll (1.0 s, opt-in, gated).
- No GPL code. Only dependency: `ungive/mediaremote-adapter` **v0.7.7 (BSD-3-Clause)**, bundled as a helper, never linked.
- No Accessibility, Screen Recording or Input Monitoring. Apple Events only on first use of scripted media controls.
- No sandbox entitlements. No force unwraps, `try!`, `fatalError`, or `print` outside tests.
- All user-facing strings via `String(localized:)`. Logging via `Log.<category>` (`os.Logger`).
- Features never import each other.
- Never use "Dynamic Island" anywhere.

## Verification model

This repo is authored on Windows. **Compilation and unit tests run on GitHub Actions (`macos-15`).**
Each task's "run the tests" step = push, then read `ci-logs` branch (`build.log`, `test.log`) via
`https://raw.githubusercontent.com/lokeshdeep42/notch/ci-logs/<file>`. Hardware behaviour goes to
`docs/VERIFY-ON-MAC.md`. CI also uploads an ad-hoc-signed `Sill.app` artifact for the test Mac.

## Cross-module interfaces (the contract every task codes against)

```swift
// Services
public enum Branding { static let appName: String; static let bundleID: String; static let helpURL: URL }
public enum Log { static let app, notch, hover, display, media, shelf, clipboard, power, settings: Logger }
@MainActor public final class Preferences: ObservableObject {
  public static let shared: Preferences
  @Published enterDelay: Double /*s, 0.18*/, exitDelay: Double /*0.25*/, deadZone: Double /*pt, 3*/,
             intentHover: Bool /*true*/, displayMode: DisplayMode /*.builtInOnly*/,
             chosenDisplayUUIDs: [String], pillWidth: Double /*185*/, showBatteryWhenCollapsed: Bool /*false*/,
             nowPlayingEnabled: Bool /*true*/, shelfEnabled: Bool /*true*/, clipboardEnabled: Bool /*false*/,
             powerEnabled: Bool /*true*/, clipboardPaused: Bool, clipboardMaxItems: Int /*200*/,
             clipboardBlocklist: [String], shelfMaxItems: Int /*100*/, shelfMaxBytes: Int64 /*2 GB*/,
             isPaused: Bool, hasCompletedOnboarding: Bool, debugOverlay: Bool
}
public enum DisplayMode: String, CaseIterable { case builtInOnly, all, chosen }
public struct CostSample { cpuSeconds: Double; wakeups: UInt64; footprintBytes: UInt64; uptime: TimeInterval
                           static func current() -> CostSample? }
public struct CostReceipt { init(sample: CostSample); cpuPercent: Double; wakeupsPerHour: Double;
                            footprintMB: Double; summary: String }

// NotchCore
public enum NotchPhase { closed, pending, open, closing, peek, suppressed }
public enum NotchEvent { pointerEntered, pointerExited, enterDelayElapsed, exitDelayElapsed,
                         intentConfirmed, intentRestart, clicked, dragApproached, dragEnded,
                         peekRequested, peekElapsed, collapseRequested, suppress, unsuppress }
public enum NotchEffect { scheduleEnter, scheduleExit, schedulePeekEnd, cancelTimers }
public struct NotchStateMachine { phase; isPointerInside; mutating func send(_:) -> [NotchEffect] }
public struct HoverIntent { Config; enum Verdict { none, confirm, restart };
                            mutating func reset(); mutating func add(point: CGPoint, time: TimeInterval) -> Verdict }
public struct NotchGeometry { screenFrame; notchSize; hasHardwareNotch;
  static func resolve(screenFrame:safeAreaTop:auxLeftWidth:auxRightWidth:menuBarHeight:fallbackWidth:) -> NotchGeometry
  func windowFrame() -> CGRect; func collapsedRect(extraWidth:) -> CGRect /* panel space, top-left origin */
  func expandedRect() -> CGRect; func hoverRect(deadZone:) -> CGRect }
@MainActor public protocol NotchModule: AnyObject {
  var id: String { get }; var title: String { get }; var symbolName: String { get }
  var isEnabled: Bool { get }; var wantsKeyboardFocus: Bool { get }
  func makeExpandedView() -> AnyView; func makeHeaderAccessory() -> AnyView?
  func activate(host: NotchHost); func deactivate() }
@MainActor public protocol NotchHost: AnyObject {
  func setWings(_ wings: WingContent?, from moduleID: String)
  func requestPeek(_ peek: PeekContent); func requestCollapse(); func select(moduleID: String) }
public struct WingContent { priority: Int; leading: AnyView; trailing: AnyView; width: CGFloat }
public struct PeekContent { leading: AnyView; trailing: AnyView; width: CGFloat; duration: TimeInterval }
@MainActor public final class NotchHub: ObservableObject, NotchHost  // shared across panels
  { modules; enabledModules; selectedModuleID; wings; peek; func register(_:); func refreshModules() }
```

### Task 1: Package skeleton, CI, scripts, Services basics

**Files:** Create `Package.swift`, `App/*`, `Sources/Services/{Branding,Log,Preferences}.swift`, `Sources/DesignSystem/*`, `Scripts/*`, `.github/workflows/ci.yml`, one smoke test.

- [ ] Write `Package.swift` with the targets above (IOKit linked to Services/Power, QuickLookThumbnailing to Shelf).
- [ ] App boots as accessory with status item menu: Settings…, Pause, Quit (M0-T1).
- [ ] `build.sh` assembles `build/Sill.app` (+ adapter if `Vendor/` built) and ad-hoc signs; `test.sh` runs `swift test`; `run.sh`; `fetch-adapter.sh` clones v0.7.7 recursively and runs cmake.
- [ ] CI: build, test, bundle, push `build.log`/`test.log` to `ci-logs`, upload `Sill.app.zip` artifact.
- [ ] Push; CI green → commit.

### Task 2: NotchStateMachine (M2-T1)

Tests (`NotchStateTests`): closed+enter→pending [cancel, scheduleEnter]; pending+delay→open; pending+intentConfirmed→open; pending+exit→closed; pending+intentRestart→pending [cancel, scheduleEnter]; open+exit→closing [scheduleExit]; closing+enter→open [cancel]; closing+delay→closed; closed+peek→peek [schedulePeekEnd]; open+peek→open []; peek+elapsed→closed; peek+enter→pending; closed+drag→open; open+dragEnded (pointer outside)→closing; open+dragEnded (pointer inside)→open; any+suppress→suppressed [cancel]; suppressed ignores everything but unsuppress; clicked from closed→open; collapseRequested→closed [cancel]; stale enterDelayElapsed while closed → no-op.

### Task 3: HoverIntent

Tests: slow drift over ≥40 ms → `.confirm`; single sample → `.none`; fast upward (vy > 900 pt/s) → `.restart`; fast downward → `.none`; samples older than window are dropped; reset clears.

### Task 4: NotchGeometry (M0-T4, M2-T7)

Tests: notched 14" (1512×982, safeTop 32, aux 663.5 each → notch 185×32); non-notched uses fallback width and menu-bar height (min 24); window frame is top-centred on a screen with negative origin; hoverRect excludes the top `deadZone` points; collapsedRect widens symmetrically with `extraWidth`.

### Task 5: Cost receipt (M0-T8 support)

Tests: `CostReceipt` from a synthetic sample (3.6 s CPU over 3600 s → 0.1%; 360 wakeups/h; formatting uses 3 decimals below 1%).
`CostSample.current()` uses `task_info(TASK_POWER_INFO_V2)` and `TASK_VM_INFO.phys_footprint`.

### Task 6: Panel engine (M0-T3, M2-T4…T6, M2-T9)

`NotchShape` (animatable width/height/radii), `NotchPanel`, `PassthroughView` (flipped, hit-tests against `activeRect`, tracking area on `hoverRect`, forwards enter/exit/move), `PanelModel`, `NotchRootView` (collapsed/wings/peek/open layouts, 50 ms content stagger, reduce-motion cross-fade, cost receipt footer), `NotchPanelController` (runs effects with cancellable `Task.sleep`, feeds `HoverIntent`), `NotchHub`, `DebugOverlay`.

### Task 7: Window manager (M0-T5…T7, M2-T2, M2-T8)

`NotchWindowManager`: controllers keyed by `CGDirectDisplayID`; desired set = display mode ∩ not fullscreen ∩ not paused ∩ session active ∩ screens awake; debounced (300 ms one-shot) idempotent reconcile; geometry change → rebuild controller. `FullscreenDetector` via `CGWindowListCopyWindowInfo` bounds (no permission). Observers: screen params, wake/sleep, session, active space, app activation.

### Task 8: DragMagnet

Global monitors `leftMouseDragged`/`leftMouseUp` (no permission; zero events when not dragging). Active only when drag pasteboard `changeCount` changed and contains file URLs. Reports distance-based `strength` and `x` to controllers; `strength ≥ 0.85` → `.dragApproached` + select shelf; mouse up → `.dragEnded`. PassthroughView accepts the drag inside `hoverRect` while a file drag is active.

### Task 9: Now Playing (M3)

Decoder tests (`NowPlayingDecoderTests`): full payload → info; diff merges; `null` removes key; empty payload → nothing playing; malformed line → ignored; `--micros` fields convert to seconds; `elapsed(at:)` extrapolates only when playing.
Service chain: `AdapterProcess` (perl `stream --micros --debounce=100`, backoff 1-2-4-8-16 s, give up after 5 fast failures) → `DistributedMediaSource` (Music/Spotify notifications; controls via `NSAppleScript`, first-use explanation) → empty state. Artwork downsampled to 160 px off main; average colour tint. Views: expanded player, collapsed wings (static), track-change peek.

### Task 10: Shelf (M4)

Store tests (`ShelfStoreTests`, temp dir): add copies file (delete original → item intact); manifest round-trips; `clearUnpinned` keeps pinned; prune by count and by bytes removes oldest unpinned first. Importer handles file URLs, image data (→ PNG), plain text (→ .txt) off main. `ThumbnailCache` via `QLThumbnailGenerator`. `ShelfItemInteractionView` (AppKit) = click/⌘-click select, double-click open, drag-out with `NSURL` writers and `.copy` mask, context menu (Reveal, Share, Pin, Remove).

### Task 11: Clipboard (M5)

Filter tests: concealed/transient/auto-generated types rejected; blocklisted source rejected; ordinary text accepted. Store tests: dedupe consecutive identical text; cap by count; survives reload. `ClipboardMonitor`: 1.0 s timer (tolerance 0.5), 10 s when user idle > 5 min, stopped when disabled/paused/screens asleep/session inactive; ignores its own writes. Views: disabled explainer with cost note, search field auto-focus, ↑/↓, Enter copies + collapses, Esc collapses.

### Task 12: Power (M6)

`PowerMonitor` via `IOPSNotificationCreateRunLoopSource`; health/cycle from `AppleSmartBattery` read on panel open. Header accessory (percentage + bolt), battery tab, plug/unplug peek, optional collapsed wing. Unavailable on Macs without a battery.

### Task 13: Settings, onboarding, launch at login, permissions (M1-T3, M7)

Settings tabs: General (launch at login with real status, displays, pause, pill width, battery wing), Hover (delays, dead zone, intent toggle, live "try it"), Modules (toggles with cost notes, clipboard retention + blocklist, shelf caps), Advanced (debug overlay, open data folder, reset), About (version, acknowledgements). Onboarding: 3 skippable pages. `PermissionService` re-checks Apple Events status on wake/activate.

### Task 14: Docs

ADR entries for every decision; `docs/VERIFY-ON-MAC.md`; corrections in `01`/`02`; README quick-start.
